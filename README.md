## Overview
A testing suite for a banking application that allows users to track their expenditures by submitting and searching through them.

### Set Up
Before we begin coding, let's complete the initial setup for this lesson:

#### Fork and Clone
1. Go to the provided GitHub repository link.
2. Fork the repository to your GitHub account.
3. Clone the forked repository to your local machine.

#### Open and Run File
1. Open the project in VSCode.
2. Run `npm install` to install all necessary dependencies.



- Open the React application in the browser:
   ```sh
   npm run dev
   ```-. Run the included backend:
   ```sh
   npm run server
   ```
- Create a test branch.

#### Display Transactions Test
- Create a test suite that will test if transactions are displayed on startup.
